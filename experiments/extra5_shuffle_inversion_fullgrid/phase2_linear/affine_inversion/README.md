# Phase 2D — Exact shuffle-invariant affine-hull inversion

**Status (2026-10-31):** unrestricted planted-state recovery validated for specifically pinned GF(2)-linear raw-output generators. The production EXTRA 5 RNG/state is **UNKNOWN**.

## Invariant and proof

For each unordered 5-of-35 set S, enumerate all possible fourth-removal indices A(S), without assuming any published extraction order. Indices lie in [0,31], so identify them with 5-bit vectors over GF(2). For v0 in A(S), let V be the linear span of {v XOR v0 : v in A(S)}. For every vector a in the orthogonal complement of V, the parity of (a AND v) is constant for all v in A(S).

If the fourth-output index bits are a **linear projection** L_d(s) of the unknown initial state s, each such parity yields an exact state equation:

    a · L_d(s) = a · v0  (mod 2)

We derive a maximal independent family of these equations from each unordered ticket, then run exact GF(2) elimination. Contradictory equations are model-specific **UNSAT**; full-rank equations give a unique state which must pass independent full-ticket replay. Rank deficiency without a contradiction is **UNKNOWN**, not an exclusion.

**Complete combinatorial census:** out of 324,632 possible tickets, 181,456 give zero independent equations, 120,868 give one, 20,853 give two, 1,424 give three, and 31 give four. Thus 143,176 combinations (44.1%) yield at least one linear parity constraint.
