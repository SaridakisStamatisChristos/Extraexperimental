# State-origin alias under an initially rejected PRNG word

**Claim (conditional).** Let a persistent deterministic generator with transition `T` emit `O(s)` from a state `s` and then transition to `T(s)` (or transition first, according to a consistently pinned convention). Let a rejection sampler discard each unacceptable word without emitting a ticket, and emit one ticket for each acceptable word. Suppose initialization at state `s` produces an unacceptable first word, then an acceptable second word. If the sampler introduces no observable initialization marker and the two runs use identical after-ticket gap semantics, the stream of emitted tickets from initial state `s` is identical to the stream initialized at its one-step-forward state `T(s)`, provided both start before the same first accepted output and then share all subsequent generator states. The two initial states are thus observationally indistinguishable using tickets alone.

**Proof.** Initialization at `s` consumes `O(s)` and discards it. The next word emitted is `O(T(s))`; the program initialized at `T(s)` emits that same word as its first. Both emit the same ticket and enter identical states following that accepted word. Determinism inductively implies the same words, rejection decisions, future accepted tickets and after-ticket gap behavior forever. QED within these assumptions.

**Witness.** The `test_first_rejection_alias_nonidentifiability` fixture constructs a Marsaglia xorshift128 32-bit first word equal to `0xffffffff`, outside the conventional acceptance threshold `4294881360`. The recovered state with zero skips is precisely the original state's one-step successor; it reproduces all 180 synthetic tickets including reserved continuation. Requiring one initial rejection explicitly recovers the original planted seed. This is a statement of underdetermination, not a defect of the solver.

**Consequence.** A recovered forward state can support full continuation for a pinned synthetic generator without identifying the historical pre-rejection seed. Distinguish *trajectory-equivalence* from *original-state identification* in every report and freeze.
