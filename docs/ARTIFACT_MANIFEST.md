# Research archive manifest — completed recovery

**Archive refresh: 29 October 2026.** The repository remains a documentation-first exploratory research project. No CI, Actions workflows, or live draw scraper were added.

## Archived

- Research history, original cryptographic literature trail, methodological cautions, provenance and continuation guide.
- All experiment Python scripts, including a new local reproducibility driver and figure renderer.
- 20-draw and 100-draw chronological CSV datasets; full 9,360-row algorithm comparison scores CSV.
- Aggregate audit JSON, sampler-forensics JSON, pilot diagnostics JSON and mass benchmark diagnostics JSON.
- Four SVG figures and four regenerated PNG visualizations under `figures/`.
- Text reports and clearly labeled synthetic-only demonstration data.

## Intentional build artifact not in Git

`experiments/extra5_mass_algorithm_holdout_masks.npz` is a **670 KB, 9,360 × 20 UInt64 candidate-ticket cache**, not unique source data. It is generated by running `extra5_mass_algorithm_benchmark.py`, then consumed by `extra5_mass_algorithm_calibration.py`. It is ignored by `.gitignore` to avoid storing an intermediate binary as source. The local regeneration script recreates it automatically.

## Rebuild from a clone

```bash
python -m pip install -r requirements.txt
cd experiments
python extra5_regenerate_all.py
```

This will recompute all derived analyses and PNGs from the committed historical datasets. It is deterministic under the original environment, but cross-version numerical/runtime differences may alter some serialization or benchmark timing.

**Source caveat:** Archived results come from third-party websites, not an operator-certified 2026 archive. The figures are faithful visualizations of archived metrics but regenerated raster images are not pixel-identical to earlier local figures. The JSON diagnostic files contain restored computed values rather than an externally certified audit. The benchmark remains retrospective and has no validated predictive value.
