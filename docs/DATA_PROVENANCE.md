**Audit warning:** Raw records were manually transcribed from third-party results and not verified line by line against a complete official operator export. Stored sorted tickets do not preserve any original internal generator output order. Historical count and draw-ID numbering can disagree if cancelled/omitted draws exist; do not assume completeness outside explicitly listed intervals.

Do not treat generated `extra5_test_synthetic.csv` as historical data; that file is a synthetic input for testing parser/analysis workflows.

Reproducibility requires pinning input snapshots, code versions, random seeds and software dependencies; archived outputs are tied to the stated 2026 snapshots and should not be silently overwritten by later results.
